## Project Overview

This project documents the phases of a cybersecurity incident-handling process, from preparation through post-incident activity. It combines structured analysis, security concepts, and a simulated incident scenario to demonstrate how an analyst can investigate, contain, recover from, and learn from a security event.

The documentation is organized into individual modules to make each phase easier to understand and review.

## Scenario

**Scenario Name:** Insight Nexus Breach

> This is a simulated training scenario created for cybersecurity learning and portfolio purposes. No real organization, system, account, or confidential data is involved.

The scenario is analyzed as a potential security incident involving suspicious activity that requires preparation, detection, analysis, containment, eradication, recovery, and post-incident improvement.
